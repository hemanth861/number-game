# Number Guessing Game

A simple, interactive number guessing game built with HTML, CSS, and JavaScript. Features colorful UI, difficulty levels, attempt tracking, hints, and persistent high scores.

## Features

- **Guessing Game**: Try to guess a random number between 1 and 100
- **Difficulty Levels**: Easy (unlimited attempts), Medium (10 attempts), Hard (5 attempts)
- **Colorful UI**: Modern gradient design with smooth animations
- **Attempt Tracking**: Keep track of your guesses and remaining attempts
- **Guess History**: View all your previous guesses
- **Hints**: Get hints to narrow down your search
- **High Score**: Your best score (fewest attempts) is saved in local storage
- **Responsive Design**: Works on desktop and mobile devices

## How to Play

1. Open `index.html` in your web browser
2. Select your preferred difficulty level
3. Enter a number between 1 and 100 in the input field
4. Click "Guess" or press Enter
5. Follow the hints (Too high/Too low) to find the correct number
6. Click "New Game" to start over
7. Click "Give Hint" for additional help

## Files

- `index.html` - Main HTML structure
- `style.css` - All styles and animations
- `app.js` - Game logic and interactivity

## Technologies Used

- HTML5
- CSS3 (Flexbox, Grid, Animations, Gradients)
- Vanilla JavaScript (ES6+)
- Local Storage API

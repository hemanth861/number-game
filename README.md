# Number Guessing Game

A modern number guessing game built with HTML, CSS, and JavaScript.

## Features

- Guess a secret number between 1 and 100
- Difficulty levels: Easy (unlimited), Medium (10 attempts), Hard (5 attempts)
- Scoring system with total score, best round, and fewest-attempts high score
- Voice assistant that reads feedback, hints, and game information aloud
- Guess history with too-high / too-low indicators
- Responsive, mobile-friendly interface with accessibility support

## Files

- `index.html` - Game structure
- `style.css` - Game styling
- `app.js` - Game logic

## How to Run

Open `index.html` in your web browser and start playing.

## Controls

- **Guess** - Submit your guess (or press Enter)
- **New Game** - Start a fresh round
- **Give Hint** - Get a range hint after your first guess
- **Voice** - Toggle automatic voice feedback
- **Hear Info** - Read the current difficulty, attempts, last guess, and score aloud

Voice uses the browser's built-in Speech Synthesis API. It is available in most modern browsers.
